领域时间线与宏观趋势

Timeline · Taxonomy evolution · 与上方 README 分区同源对照（本站撰写）
阅读范围：本节依据仓库快照 streaming-video-understanding-source.md 中的日期列与各分区标签归纳；不代表学术界完整普查。技术细节请以论文 PDF / OpenReview / 代码仓库为准。

三代范式递进（概念轴）

  • 第一代（交互语法）：以 EOS / 沉默 / 信息头等特殊 token把「说不说」写进自回归目标（如 VideoLLM-online、ViSpeak、早期 informative head 路线）。
  • 第二代（记忆—延迟）：无限流场景下用滑窗 + KV 驱逐 / 分层卸载保持常量显存；代表性路线含 StreamingVLM、各类 StreamKV / InfiniPot 系列。
  • 第三代（意图对齐 + 推理内化）：2026 清单密集出现「何时回应由证据与查询共同决定」「边看边想（streaming CoT）」「推理痕迹压缩为记忆」三条支线，将触发、记忆与 thinking 模块联合设计。

2025→2026 迁移的三个信号

  • 查询感知（Query-aware）：从「有变化就重要」转向「与用户意图相关的变化才值得保留 token」，如 QueryStream 的差分剪枝与相关性触发回应。
  • 结构化触发：扩散 / 去噪、序列级 activation、gray-scale 门控等，把 timing 从启发式变成可学习或可优化的序列对象（STRIDE、ColorTrigger 等）。
  • 系统协同：Codec 侧运动矢量、I-frame 锚点与 RoPE 校正（CodecSight）、CUDA Graph、Prefix KV 复用（AURA）等全栈优化与算法并列出现。

简史时间线（与清单日期对齐的里程碑）

2024 · 下半年

交互格式探索：MM-Duet 等工作把「何时插入文本反馈」与视频推进绑定；StreamingBench、OVO-Bench 等评测逐步确立回溯 / 实时 / 前瞻切片。

2025 · 全年

记忆与压缩爆发：分层 KV、检索式记忆、token 削减、边缘卸载大量出现；StreamMind、Open-ended Hierarchical Streaming 等走向事件门控 + 稀疏调用大模型。

代表性收录：StreamingVLM（长流常显存）、Flash-VStream、StreamKV、StreamingTOM 等 —— 详见表格「Memory」「Real-time Inference」分区。

2026 · Q1–Q2（清单）

触发 × 推理 × 部署：同一时段并列出现 ThinkStream / VST / Think While Watching（流式思维）、STRIDE / StreamReady / ColorTrigger（时机建模）、HERMES / FluxMem / FlexMem / CurveStream（层级与几何记忆）、CodecSight / SimpleStream（codec 与强基线）。产品侧 Seed2.0、Proact-VL、AURA 强调实时助手形态。

综合对比结论（供选型）

  • 若以最低接入成本为先：SimpleStream、Training-free 的 QueryStream 插件式剪枝、或 StreamMind 类浅层门控可作为第一站。
  • 若以长流语义一致性为先：优先考察层级 KV / 曲率–频率混合记忆（HERMES、FluxMem、CurveStream、FreshMem）与推理摘要记忆（ThinkStream）。
  • 若以人机共生交互为先：AURA / Proact-VL / Seed2.0 产品线论文通常 bundled benchmark，适合做端到端场景对齐。
